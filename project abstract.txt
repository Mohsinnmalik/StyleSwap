AI Powered Virtual Garment Try On System for Smart Retail Showrooms

Traditional clothing retail requires customers to try garments, which can create fitting room queues increase garment handling and limit the efficiency of product exploration. This project presents Tryonity, a web based AI garment try on system designed to improve the shopping experience in physical retail showrooms. The proposed system integrates a customer facing web interface, a retailer catalogue management dashboard, cloud based image storage, a database and an AI virtual try on model. Customers can browse garments from an updated catalogue, select products and generate a visualisation of themselves wearing a selected garment. A session code mechanism connects the customer workflow with the showroom display while retailers can add and remove catalogue items through the management interface. The system has been implemented as a working software prototype and its core AI image generation workflow is functional. The project demonstrates the integration of generative AI with web technologies for smart retail applications without requiring customers to install a dedicated mobile application. Further work will focus on visual quality evaluation, processing time measurement, garment detail preservation and complete look generation. The proposed system offers a foundation for evaluating AI assisted garment visualisation, in physical retail environments.
